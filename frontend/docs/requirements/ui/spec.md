# UI グローバルスタイル仕様

## 概要

アプリ全体に適用するUIスタイルの基本方針。
機能別仕様には含まれない、横断的なスタイル設定をここで管理する。

---

## フォントサイズ

### 基本設定

```css
html {
  font-size: 105%;
}
```

- ブラウザ標準（16px）の 105% = 16.8px をベースとする
- `rem` / `em` を使うコンポーネントに自動的に適用される

### 背景

- もともと `zoom: 1.05` を `html, body, #root` に設定していたが、`100vh` と `height: 100%` の計算結果が乖離するレイアウトバグを引き起こした（#6）
- `zoom` を削除し、フォントスケールのみ `font-size: 105%` で代替することにした

### 注意

- FluentUI v9 のコンポーネントはフォントサイズを `px` 固定のトークンで持つものもある
- `font-size: 105%` が効かない箇所は FluentUI のテーマトークンを上書きして対応する（対応が必要になった時点で追記する）

---

## レイアウト基本方針

### 高さの扱い

- ルート要素（`html, body, #root`）は `height: 100%` で統一する
- `AppShell` は `height: 100vh` を使用する
- `html/body/#root` に `zoom` を設定しない（`100vh` と `height: 100%` の計算結果が乖離するため）

### オーバーフロー

- ルート要素は `overflow: hidden` を設定する
- スクロールが必要な領域は個別コンポーネントで `overflow: auto` / `overflow-y: auto` を設定する
